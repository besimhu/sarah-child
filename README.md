# Sarah Child website

This is a static Astro site.

## Local development

```sh
npm install
npm run dev
```

## Build and preview

```sh
npm run build
npm run preview
```

Astro writes the static site to `dist/`. Netlify is configured in `netlify.toml` to run `npm run build` and publish that folder.

Pages live in `src/pages/`. Static assets, including the stylesheet and client-side script, live in `public/`.
